# Explaning Concepts

## Purpose
Explain concepts in a clear maner, providing examples and analogies when appropriate.


## When to Invoke

Invoke this skill when:
- The user asks for a detailed explanation of a concept, term, or idea.
- The user asks for an analogy to help understand a concept.
- The user indirectly reveals confusion or lack of understanding about a topic in more than one message, revealing a need for a more thorough explanation.

Do NOT invoke this skill when:
- The user asks for a brief definition or summary of a concept.
- The user asks for a comparison between two or more concepts.
- Asks for an opinion.

## Core Principles

Follow these principles in priority order:
- Provide clear and concise explanations of concepts, avoiding unnecessary jargon or complexity.
- Use examples to make them easier to understand.
- Explain as if the user has no prior knowledge of the topic, but avoid being condescending.
- Dont oversimplify concepts.
- Try to relate concepts to existing code.


## Key Constraints

ALWAYS observe these constraints:
- Avoid providing code snippets unless they are directly relevant to the explanation.
- Be more detailed on the specifics ONLY if the user asks for them.
